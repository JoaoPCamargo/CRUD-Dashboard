# ChronicaVerse-App

**Sistema de gerenciamento de coleção de quadrinhos com análise de dados integrada.**  
Permite organizar, cadastrar e consultar revistas e séries, com interface interativa em Python, leitura de arquivos CBR e dashboards de visualização de dados.

---

## 🚀 Sobre o Projeto

O ChronicaVerse-App vai além do simples gerenciamento de quadrinhos:

- **Página inicial intuitiva:** Acesso rápido às funções de cadastro, filtros avançados, leitor de arquivos CBR e dashboards.
- **CRUD completo:** Cadastro e edição de revistas, séries, autores, artistas e gêneros.
- **Filtros inteligentes:** Pesquise por editora, saga, arco, autor, artista, gênero e avaliação.
- **Leitor de arquivos CBR integrado:** Leia suas revistas digitais direto no aplicativo.
- **Dashboards interativos:** Visualize gráficos de leitura, avaliações, progresso por série e tendências de consumo.
- **Análise de dados:** O sistema organiza e processa informações para gerar insights sobre sua coleção.

Este projeto demonstra habilidades em **manipulação de dados, visualização de informações, integração de interfaces gráficas e automação de processos** — competências valiosas para estágios em Ciência de Dados.

---

## 🛠️ Funcionalidades

- Cadastro e gerenciamento de quadrinhos, séries e autores
- Filtros avançados por múltiplos critérios
- Leitura de arquivos CBR diretamente no aplicativo
- Dashboards com gráficos de avaliação, progresso de leitura e estatísticas gerais
- Interface gráfica interativa em Python
